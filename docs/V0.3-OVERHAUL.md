# NIRUPI v0.3 overhaul — migration, theme and custom apps

This release turns NIRUPI from a "preserve everything" installer into a
non-destructive, idempotent migration engine with a single-source dark theme.

## 1. Migration engine (`lib/migrate.sh`)

- Installed state is recorded in `~/.local/state/nirupi/installed.env`
  (`NIRUPI_VERSION`, `NIRUPI_SCHEMA`, `NIRUPI_DISTRO`, `NIRUPI_SESSION`).
- `detect_legacy_layout` classifies existing binaries, symlinks and configs.
- Configuration files are merged by `managed_config_install` (three-way merge):
  - managed + unmodified → upgraded in place;
  - modified or untracked → preserved, with a `*.nirupi-new` proposal.
- Foreign binaries/symlinks are archived (never deleted) to
  `~/.local/state/nirupi/legacy/<run>/` with a verified backup before linking.
- `nirupi migrate plan|diff` prints a read-only migration report.
- `nirupi migrate dwm --rebuild` rebuilds DWM from the deployed sources and the
  effective user config, then atomically re-links it.

## 2. Rollback (`lib/rollback.sh`)

- `nirupi rollback --all` restores the latest config backup and binary links.
- `nirupi rollback --configs RUN_ID` restores configs from one backup run.
- `nirupi rollback --binaries` restores the six binary links only.
- Every path is validated before any change; a local TTY and confirmation are
  required. Packages, SDDM and system files are never touched.

## 3. Theme engine (`lib/theme.sh`, `vendor/noir/theme/tokens.env`)

- `tokens.env` is the single palette/typography source.
- `nirupi theme apply|status|diff` and `./install.sh --theme-only` deploy it to
  `st`, `kitty`, `alacritty`, `fish`, `tmux`, `lazygit`, `micro`, `aerc`,
  `dunst`, `picom`, `rofi`, `cmus`, GTK 2/3/4 and browser flags.
- `runtime-session.sh` exports the dark GTK/Qt environment and starts `picom`.

## 4. Custom apps (`lib/apps.sh`)

- `~/.config/nirupi/apps.conf` (or `custom_apps.conf`) lists extra packages per
  distro and external Git repositories to clone/build.
- Absent file → non-interactive default install. Only HTTPS/SSH URLs and
  validated package names are accepted.

## Recommended upgrade runbook

1. Back up the machine (disk image or snapshot).
2. `bash tests/smoke.sh`
3. `bash install.sh --diff`
4. `bash install.sh --plan`
5. From a local TTY: `bash install.sh --apply --session sddm|startx`
6. `bash install.sh --verify` and `nirupi doctor`
7. Log in and test DWM, terminals, theme, sound, lock and reboot.
