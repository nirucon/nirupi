# NIRUPI v0.4 — "Noir Bar & Agent"

A larger release that turns the desktop into a cohesive, self-updating
environment while staying minimal.

## Status bar 2.0
- Real Noir colors in the bar via the **status2d** dwm patch.
- **Clickable segments** via the **statuscmd** (nosignal) dwm patch:
  - agent icon -> opencode, volume scroll/mute, weather, network, updates,
    Nextcloud, control center.
- Fixed CPU/Bluetooth segments; temperature always shown (hwmon, °C) with a
  warning marker; battery time remaining; microphone-mute, DND and
  screen-recording indicators.
- Provider cache for kernel/host/network/Nextcloud; weather defaults to
  **Ljungskile, Sweden**.

## dwm / suckless
- Upgraded to **dwm 6.8** (incl. the `getatomprop` regression fix) and
  **slock 1.7** (ctrl-u clears input). st 0.9.3 and dmenu 5.4 were current.
- Added **status2d**, **statuscmd (nosignal)** and **xresources** on top of the
  existing pertag, gaps, ewmhtags, movestack, rotatestack, scratchpad and
  centeredmaster patches.

## Agent
- `opencode` is installed automatically (npm, then the official installer).
- `nirupi agent [profile]` + `Super+a`; profiles in
  `~/.config/nirupi/agents.conf` (deepseek / codex / claude / default).
- `nirupi menu`, `nirupi keys`, `nirupi backup` and the matching keybindings
  `Super+` `` ` `` and `Super+/`.

## Unified dark theme
- One token source (`vendor/noir/theme/tokens.env`).
- Dynamic wallpaper theming via **ImageMagick** (no pywal/wallust dependency):
  `nirupi theme wallpaper IMAGE` regenerates every config + `xresources.noir`,
  `nirupi theme mode noir|wallpaper`, `Super+F5` reloads dwm colors live.
- Covers terminals, fish, tmux/lazygit/micro/aerc, GTK 2/3/4, Qt env, browser
  dark mode, dunst, picom, rofi and cmus.

## Session & safety
- DBus session bootstrap; automatic **slock after 10 min** idle (configurable
  in `~/.config/nirupi/session.conf`; xidlehook/xautolock/xss-lock fallback).
- Required + optional package lists per distro (optional is best-effort, so a
  missing package never breaks a clean install, e.g. on Void).
- All previous v0.3 guarantees remain: non-destructive migration, three-way
  config merge, archived foreign binaries and `nirupi rollback --all`.

See `docs/TEST-CHECKLIST.md` for the physical validation steps.
